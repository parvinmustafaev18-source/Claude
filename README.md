# MeshPlugin

Плагин AutoCAD для построения КЭ-сетки фундаментной плиты по чертежу и экспорта готовой схемы в ЛИРА-САПР (текстовый файл задачи).

Папка `audi-legend` к плагину не относится — это отдельный проект.

## Требования

- AutoCAD 2019+ (x64), проверено на 2019
- .NET Framework 4.8
- Visual Studio 2022 (для сборки)

Пути к DLL AutoCAD (`accoremgd`, `acdbmgd`, `acmgd`) прописаны в `MeshPlugin.csproj` и указывают на `C:\Program Files\Autodesk\AutoCAD 2019\`. При другой версии/пути AutoCAD — поправить `HintPath`.

## Работа с нескольких компьютеров

Первый раз на новой машине:

```
git clone https://github.com/parvinmustafaev18-source/Claude.git
```

Дальше два скрипта, оба двойным кликом:

- **`sync.bat`** — забрать свежую версию и отправить свои правки. Запускать
  **до** работы и **после**. Если один файл менялся на двух компьютерах и
  совместить не вышло — скрипт скажет об этом, разбирать вручную не нужно.
- **`build.bat`** — собрать и установить плагин (см. ниже).

Порядок на рабочий день: `sync.bat` → правки → `sync.bat` → закрыть AutoCAD →
`build.bat` → открыть AutoCAD → тест.

## Сборка

**Закрыть AutoCAD и запустить `build.bat`** (двойной клик). Скрипт сам найдёт
MSBuild, соберёт проект и установит плагин; при ошибке скажет, что не так.

Вручную:

```
"C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" MeshPlugin.csproj /p:Configuration=Debug /p:Platform=x64
```

Результат: `bin\x64\Debug\MeshPlugin.dll`.

Папка AutoCAD определяется автоматически (версии 2019–2026). Если AutoCAD
установлен в нестандартное место — указать явно:
`/p:AcadDir="D:\Путь\к\AutoCAD\"` (папка, где лежит `acdbmgd.dll`).

## Загрузка в AutoCAD

Плагин загружается автоматически при старте AutoCAD через autoloader-bundle:
`%APPDATA%\Autodesk\ApplicationPlugins\MeshPlugin.bundle` (PackageContents.xml + DLL).
Каждая сборка сама копирует свежую DLL в bundle (post-build шаг в csproj).

Порядок обновления: закрыть AutoCAD → собрать проект → открыть AutoCAD. Если AutoCAD
открыт, DLL занята и **сборка падает** с сообщением `ERROR: cannot copy MeshPlugin.dll
into the AutoCAD bundle` — это защита: иначе в bundle осталась бы прежняя сборка, а
тестирование шло бы на ней.

Проверка: команда `MESHHELLO` должна ответить «Плагин загружен и работает».
Каждая команда `MESH*` первой строкой печатает, какая сборка работает и откуда
загружена: `MESHQUADMESH — MeshPlugin 1.0.0.0, сборка 25.07.2026 23:06, папка …`.
Если время не совпадает с последней сборкой — AutoCAD работает на старой DLL.
Резервный способ — `NETLOAD` вручную из `bin\x64\Debug\`.

## Порядок работы

Единицы чертежа — **миллиметры**. Дуги в контурах не допускаются (ЛИРА их не принимает) — заменять хордами.

1. **`MESHLAYERS`** — выбрать контур плиты (замкнутая полилиния) и, если уже есть, линии сетки. Спросит толщину плиты и разложит: контур → слой `FOUNDATION_SLABS(H-300)`, отрезки → `LINE_TRIANGULATION`.
2. **`MESHWALLAXIS`** — выбрать контуры стен (замкнутые прямоугольные полилинии). Команда сама посчитает толщину по короткой стороне, построит осевую линию и положит её в слой `WALLS(H-200)`. Исходные контуры не трогаются. Непрямоугольные контуры (Г-образные и т.п.) пропускаются — для них построить ось вручную и оформить через `MESHWALLS`.
   Либо вручную: **`MESHWALLS`** — выбрать уже начерченные осевые линии стен, указать толщину. Для каждой толщины — свой вызов команды.
   При зазорах в углах: **`MESHWALLJOIN`** — выбрать оси, указать максимальный зазор (по умолчанию 500 мм). Непараллельные оси продлеваются до пересечения (только удлинение), коллинеарные одного слоя сливаются в один отрезок.
3. **`MESHCOLUMNCROSS`** — выбрать сечения пилонов (замкнутые прямоугольные полилинии без поворота). Пилон моделируется **одной осевой линией-пластиной** вдоль длинной стороны сечения (толщина = короткая сторона), в слое `WALLS(H-300 PILON)`. Дальше это обычная стена: сетка проходит сквозь пилон, а узел точно в центре поперёк оси `MESHQUADMESH` обеспечивает сама (принудительно врезает перпендикуляр через середину оси-пилона). При экспорте — вертикальные пластины КЭ 44. Исходный контур и старые точки центров удаляются.
   Запасной вариант: **`MESHCOLUMNSBAR`** (старый режим, пилон стержнем) — контур в слой `COLUMNS(SEC-RC_RECT B-600 H-300)` + точка центра; внутренность пилона остаётся пустой, при экспорте — стержень КЭ 10.
4. **`MESHDOORS`** (по желанию) — дверные проёмы в стенах. Начертить отрезок **поверх оси стены** на длину проёма, вызвать команду, задать высоту двери (по умолчанию 2100 мм) и выбрать эти отрезки. Отрезки уйдут в слой `WALL_DOORS(H-2100)`, а в середине каждого появится квадрат 200×200 в слое `WALL_DOORS_MARKS` — обозначение для чертежа, в ЛИРУ оно не экспортируется. При экспорте стена под проёмом не выдавливается от пола до заданной высоты, выше остаётся перемычка. Чертить дверь **после** `MESHQUADMESH` не нужно — порядок обратный: сначала `MESHDOORS`, потом сетка.
5. **`MESHCHECK`** (рекомендуется перед сеткой) — выбрать контур плиты и шаг. Команда ничего не строит и ничего не переносит: за один проход проверяет весь чертёж и выдаёт **сразу весь** список замечаний — контур (замкнут, без дуг, без самопересечений, углы 90°), стены/пилоны/отверстия внутри плиты, двери на осях стен, задвоенные оси, объекты на слоях, которые построение не увидит, оценка числа ячеек при заданном шаге. Проблемные места отмечаются кругами в слое `ПРОБЛЕМА`. Смысл — исправить всё за один заход, а не по одной ошибке за запуск.
6. **`MESHQUADMESH`** — выбрать контур плиты, задать шаг сетки (300/400/500). Построит сетку: квадраты внутри, обрезка по контуру, врезка стен и пилонов, сварка коротких рёбер, сглаживание. Стены и пилоны при необходимости подвигаются к линиям сетки (до 100 мм).
7. **`MESHCLEAN`** (по желанию) — удаляет из модели всё вне служебных слоёв плагина: подоснову, контуры стен, мусор. Показывает количество и просит подтверждение (по умолчанию No). Объекты в заблокированных слоях пропускаются. Отмена — Ctrl+Z.
8. **`MESHEXPORTTXT`** — выбрать контур плиты. Толщину возьмёт из имени слоя контура, класс бетона — выбором (B25–B40 или Manual). Спросит высоту этажа и шаг разбивки стен по высоте. Создаст текстовый файл задачи в `LIRA_PLANS\<имя_чертежа>_LIRA.txt` рядом с DWG.

## Импорт в ЛИРА-САПР

Файл → Импортировать задачу → тип «Текстовые файлы (*.txt)». После импорта — «Упаковка схемы».

Что попадает в задачу: плита — пластины КЭ 41/42/44 (z=0), стены и оси пилонов (`MESHCOLUMNCROSS`) — вертикальные оболочки КЭ 44 на высоту этажа, пилоны старого режима (`MESHCOLUMNSBAR`) — стержни КЭ 10 от центра сечения вверх. Жёсткости: плита, стены и оси пилонов — GEI по толщинам, пилоны-стержни — S0 по сечениям из имён слоёв. Опоры/коэффициенты постели **не экспортируются** — задать в ЛИРЕ вручную.

## Замечания по слоям

Параметры читаются из имён слоёв, формат менять нельзя:

| Слой | Что кодирует |
|---|---|
| `FOUNDATION_SLABS(H-300)` | толщина плиты, мм |
| `WALLS(H-200)` | толщина стены, мм |
| `WALLS(H-300 PILON)` | ось пилона, толщина пластины, мм |
| `COLUMNS(SEC-RC_RECT B-600 H-300)` | сечение пилона-стержня (старый режим), мм |
| `WALL_DOORS(H-2100)` | дверной проём в стене, высота, мм |
| `WALL_DOORS_MARKS` | квадраты-обозначения дверей (только чертёж, не экспортируются) |
| `LINE_TRIANGULATION` | линии сетки |
