# MeshPlugin

Плагин AutoCAD для построения КЭ-сетки фундаментной плиты по чертежу и экспорта готовой схемы в ЛИРА-САПР (текстовый файл задачи).

Папка `audi-legend` к плагину не относится — это отдельный проект.

## Требования

- AutoCAD 2019+ (x64), проверено на 2019
- .NET Framework 4.8
- Visual Studio 2022 (для сборки)

Пути к DLL AutoCAD (`accoremgd`, `acdbmgd`, `acmgd`) прописаны в `MeshPlugin.csproj` и указывают на `C:\Program Files\Autodesk\AutoCAD 2019\`. При другой версии/пути AutoCAD — поправить `HintPath`.

## Сборка

```
"C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" MeshPlugin.csproj /p:Configuration=Debug /p:Platform=x64
```

Результат: `bin\x64\Debug\MeshPlugin.dll`.

## Загрузка в AutoCAD

Плагин загружается автоматически при старте AutoCAD через autoloader-bundle:
`%APPDATA%\Autodesk\ApplicationPlugins\MeshPlugin.bundle` (PackageContents.xml + DLL).
Каждая сборка сама копирует свежую DLL в bundle (post-build шаг в csproj).

Порядок обновления: закрыть AutoCAD → собрать проект → открыть AutoCAD. Если AutoCAD
открыт, копирование в bundle упадёт с ошибкой — это ожидаемо, DLL занята.

Проверка: команда `MESHHELLO` должна ответить «Плагин загружен и работает».
Резервный способ — `NETLOAD` вручную из `bin\x64\Debug\`.

## Порядок работы

Единицы чертежа — **миллиметры**. Дуги в контурах не допускаются (ЛИРА их не принимает) — заменять хордами.

1. **`MESHLAYERS`** — выбрать контур плиты (замкнутая полилиния) и, если уже есть, линии сетки. Спросит толщину плиты и разложит: контур → слой `FOUNDATION_SLABS(H-300)`, отрезки → `LINE_TRIANGULATION`.
2. **`MESHWALLAXIS`** — выбрать контуры стен (замкнутые прямоугольные полилинии). Команда сама посчитает толщину по короткой стороне, построит осевую линию и положит её в слой `WALLS(H-200)`. Исходные контуры не трогаются. Непрямоугольные контуры (Г-образные и т.п.) пропускаются — для них построить ось вручную и оформить через `MESHWALLS`.
   Либо вручную: **`MESHWALLS`** — выбрать уже начерченные осевые линии стен, указать толщину. Для каждой толщины — свой вызов команды.
   При зазорах в углах: **`MESHWALLJOIN`** — выбрать оси, указать максимальный зазор (по умолчанию 500 мм). Непараллельные оси продлеваются до пересечения (только удлинение), коллинеарные одного слоя сливаются в один отрезок.
3. **`MESHCOLUMNS`** — выбрать сечения пилонов (замкнутые полилинии). Каждый типоразмер получит свой слой `COLUMNS(SEC-RC_RECT B-600 H-300)`, в центре сечения появится точка (узел для стержня).
4. **`MESHQUADMESH`** — выбрать контур плиты, задать шаг сетки (300/400/500). Построит сетку: квадраты внутри, обрезка по контуру, врезка стен и пилонов, сварка коротких рёбер, сглаживание. Стены и пилоны при необходимости подвигаются к линиям сетки (до 100 мм).
5. **`MESHCLEAN`** (по желанию) — удаляет из модели всё вне служебных слоёв плагина: подоснову, контуры стен, мусор. Показывает количество и просит подтверждение (по умолчанию No). Объекты в заблокированных слоях пропускаются. Отмена — Ctrl+Z.
6. **`MESHEXPORTTXT`** — выбрать контур плиты. Толщину возьмёт из имени слоя контура, класс бетона — выбором (B25–B40 или Manual). Спросит высоту этажа и шаг разбивки стен по высоте. Создаст текстовый файл задачи в `LIRA_PLANS\<имя_чертежа>_LIRA.txt` рядом с DWG.

## Импорт в ЛИРА-САПР

Файл → Импортировать задачу → тип «Текстовые файлы (*.txt)». После импорта — «Упаковка схемы».

Что попадает в задачу: плита — пластины КЭ 42/44 (z=0), стены — вертикальные оболочки КЭ 44 на высоту этажа, пилоны — стержни КЭ 10 от центра сечения вверх. Жёсткости: плита и стены — GEI по толщинам, пилоны — S0 по сечениям из имён слоёв. Опоры/коэффициенты постели **не экспортируются** — задать в ЛИРЕ вручную.

## Замечания по слоям

Параметры читаются из имён слоёв, формат менять нельзя:

| Слой | Что кодирует |
|---|---|
| `FOUNDATION_SLABS(H-300)` | толщина плиты, мм |
| `WALLS(H-200)` | толщина стены, мм |
| `COLUMNS(SEC-RC_RECT B-600 H-300)` | сечение пилона, мм |
| `LINE_TRIANGULATION` | линии сетки |
