# Проверка LIRSPLIT

Проект `LocalSplitTests.csproj` проверяет настоящее ядро `LocalSplitCore.cs`,
`SpatialGrid.cs` и допуски из `Defs.cs`. AutoCAD не требуется: тестовая
реализация `Point2d` предоставляет координаты и расстояние.

Соберите тестовый проект MSBuild из Visual Studio / Build Tools и запустите:

```bat
MSBuild tests\LocalSplitTests.csproj /nologo
tests\bin\LocalSplitTests.exe
```

Проверяются Х- и Т-пересечения, общий конец, конечная длина режущего отрезка,
несколько разрезов, тройное пересечение, разрез в 0.1 мм от конца, наложение,
вырожденный отрезок, пустой выбор и 100 поворотов/сдвигов. В каждом случае
проверяются границы области изменений, позиции разрезов, сохранение длины
и отсутствие новых разрезов при повторной обработке.

Проверка записи в AutoCAD:

1. Создайте на `LINE_TRIANGULATION` две пересекающиеся линии. Задайте им разные
   цвета/типы линий; одну можно получить из LIRBUILD, другую начертить вручную.
2. Вызовите `LIRSPLIT`, выберите одну линию: обе должны разделиться в общей
   точке, сохранив свойства. Соседние непересекающиеся объекты не изменяются.
3. Повторите команду на тех же кусках: разрезов должно быть ноль.
4. Проверьте Т-примыкание, прямолинейную замкнутую полилинию и полилинию
   с переменной шириной: добавление вершин сохраняет замкнутость и профиль ширины.
5. Отмените операцию через UNDO: чертёж должен вернуться к состоянию до команды.
6. Выберите полилинию с дугой либо заблокируйте слой: команда должна отказаться
   от изменений. Стены, пилоны и контуры отверстий не обрабатываются.

# Проверка LIRZONE

`SlabZoneTests.csproj` использует настоящее ядро SlabZoneCore.cs, SpatialGrid.cs
и допуски Defs.cs, без AutoCAD. Проверяет полное попадание треугольника/квада,
включение границы, частичное попадание, узкую выемку вогнутого контура,
выход через вершины, самопересечения/самокасания, покрытие стороны цепочкой
рёбер и разрыв/смещение цепочки, одинаковые и конфликтующие зоны,
100 поворотов и переносов в большие координаты.

```bat
MSBuild tests\SlabZoneTests.csproj /nologo
tests\bin\SlabZoneTests.exe
```

Проверка в AutoCAD после новой сборки:

1. На готовой сетке начертите два отдельных замкнутых контура по её рёбрам.
   Назначьте через LIRZONE толщину 500 мм обоим. Число узлов, линии сетки,
   геометрия и ObjectId контуров должны остаться прежними.
2. Запустите LIRLAYERS с рамкой, содержащей зоны: слои MESH_ZONES сохраняются.
3. Экспортируйте плиту: в LEGEND один дополнительный GEI 500 мм для обеих зон,
   за их пределами исходная толщина; внутри тела пилона прежняя отдельная
   жёсткость и E. Стены и стержни сохраняют свойства и номера своих типов.
4. Сравните экспорт с экспортом без контуров зон: координаты узлов, типы КЭ,
   состав и количество элементов идентичны; меняются только номера жёсткости
   пластин плиты и документ жёсткостей/легенда.
5. Повторите LIRZONE на одном контуре с новой толщиной; удаление контура зоны
   возвращает исходное назначение при следующем экспорте. Проверьте UNDO.
6. Попробуйте открытый/дуговой/самопересекающийся контур и сторону вне рёбер:
   отказ не должен менять ни один выбранный контур. Сдвиньте уже назначенный
   контур — экспорт должен отказаться до записи файла задачи.
7. Назначьте разную толщину двум совпадающим контурам: экспорт сообщает конфликт.
