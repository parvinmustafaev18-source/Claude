# Проверка LIRSPLIT

Проект `LocalSplitTests.csproj` проверяет настоящее ядро `LocalSplitCore.cs`,
`SpatialGrid.cs` и допуски из `Defs.cs`. AutoCAD не требуется: тестовая
реализация `Point2d` предоставляет координаты и расстояние.

Соберите тестовый проект MSBuild из Visual Studio / Build Tools и запустите:

```bat
MSBuild tests\LocalSplitTests.csproj /nologo
tests\bin\LocalSplitTests.exe
```

Проверяются Х- и Т-пересечения, общий конец, конечная длина режущего отрезка,
несколько разрезов, тройное пересечение, разрез в 0.1 мм от конца, наложение,
вырожденный отрезок, пустой выбор и 100 поворотов/сдвигов. В каждом случае
проверяются границы области изменений, позиции разрезов, сохранение длины
и отсутствие новых разрезов при повторной обработке.

Проверка записи в AutoCAD:

1. Создайте на `LINE_TRIANGULATION` две пересекающиеся линии. Задайте им разные
   цвета/типы линий; одну можно получить из LIRBUILD, другую начертить вручную.
2. Вызовите `LIRSPLIT`, выберите одну линию: обе должны разделиться в общей
   точке, сохранив свойства. Соседние непересекающиеся объекты не изменяются.
3. Повторите команду на тех же кусках: разрезов должно быть ноль.
4. Проверьте Т-примыкание, прямолинейную замкнутую полилинию и полилинию
   с переменной шириной: добавление вершин сохраняет замкнутость и профиль ширины.
5. Отмените операцию через UNDO: чертёж должен вернуться к состоянию до команды.
6. Выберите полилинию с дугой либо заблокируйте слой: команда должна отказаться
   от изменений. Стены, пилоны и контуры отверстий не обрабатываются.
