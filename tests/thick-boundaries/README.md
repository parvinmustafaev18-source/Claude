# Проверка разрезания сетки по утолщениям

Требуются Python 3 и .NET SDK 8. Генератор извлекает текущие методы из исходников
плагина и собирает отдельный проект с C# 7.3 вне репозитория. Используются реальные
алгоритмы разрезания, геометрии и `BuildExportCore`; для координатного типа AutoCAD
`Point2d` используется минимальная замена (X, Y, расстояние). Это проверка алгоритмов,
а не компиляция MeshPlugin.csproj и не проверка AutoCAD API или импорта в ЛИРА.

```bash
python3 tests/thick-boundaries/prepare_tests.py --output /tmp/meshplugin-thick-tests
dotnet run --project /tmp/meshplugin-thick-tests/Harness.csproj --configuration Release
```

Проверяются пересечения, касания, совпадения рёбер, разрез близко к концу,
повторный вызов, сохранение удалённых ручных линий, треугольные ячейки,
наклонный контур, баланс площадей и назначение толщины GEI 0.5 м при участке
500 мм. Изолированный контур внутри одной ячейки отклоняется.

Проверка в AutoCAD: сохранить копию чертежа, построить сетку, выбрать пересекающий
ячейки контур и вызвать LIRTHICK с толщиной 500 мм. Исходные узлы должны остаться
на месте, в пересечениях должны появиться общие узлы и рёбра границы. Повторный
вызов не должен добавлять линии. После LIREXPORT и импорта в ЛИРА проверить
толщины внутри и снаружи зоны, баланс площадей, отверстия и жёсткость пилона.
